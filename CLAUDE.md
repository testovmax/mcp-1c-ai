# Правила работы для Claude Code в этом проекте

## Поиск по конфигурации 1С

ВСЕГДА используй инструмент search_config (MCP-сервер "1c-search") для поиска
кода в конфигурации, прежде чем отвечать на вопросы о том, где что находится,
как реализована функция, где используется объект и т.п.

Не пытайся искать по файлам вручную через grep/glob по всей конфигурации —
она огромная (10500+ файлов). Семантический поиск через search_config найдёт
нужное быстрее и по смыслу.

Порядок работы:
1. Получил вопрос про код 1С -> вызови search_config с осмысленным запросом.
2. Нашёл релевантные места -> при необходимости открой конкретный файл через
   get_code или Read для деталей.
3. Только потом отвечай.

## Модель

Для этого проекта используется Claude Opus (сложный анализ кода 1С).
